03 / 04 · Kit inicial de skills

Skills prontas para o Claude, grátis no e-mail de boas-vindas.

Uma skill é um comando / que você chama dentro de qualquer conversa. Em vez de reescrever o mesmo prompt toda semana, você instala uma vez e invoca quando precisa.

  • /reuniao-em-acoes — transcrição ou anotação de reunião vira decisões, ações com dono e prazo, e pendências.
  • /briefing-de-uma-pagina — relatório, PDF ou thread longa vira uma página para quem decide, com fatos rastreáveis à fonte.
  • /onde-isso-quebra — revisa plano, proposta ou e-mail antes de enviar: premissas escondidas, pontos de falha e veredito.
  1. Assine a Behind the Prompt no formulário acima.
  2. Abra o e-mail de boas-vindas e baixe os três arquivos .zip.
  3. No Claude, vá em Personalizar → Skills.
  4. Clique em Adicionar skill, envie um .zip de cada vez e ligue a chave.
  5. Em qualquer chat, digite / e escolha a skill.

Funciona no plano gratuito do Claude. Cada skill traz dentro do arquivo a seção "Onde esta skill quebra".
