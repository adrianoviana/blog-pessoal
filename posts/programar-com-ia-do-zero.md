# Como Começar a Programar com IA: Do Zero ao Seu Primeiro App

**"Como eu começo a programar com IA?"**

Essa é a pergunta que eu recebo todo dia. No LinkedIn, no Twitter, nos comentários do YouTube. E olha, eu entendo completamente o porquê.

Em 20 anos de carreira, vi a indústria de tecnologia se transformar várias vezes. Cloud mudou tudo. DevOps mudou tudo. Mas nada — e eu digo *nada* — se compara à mudança que a IA trouxe para a forma como criamos software.

Pela primeira vez na história, você não precisa de anos de faculdade, cursos caros ou meses decorando sintaxe para criar algo útil. Você só precisa de um computador e vontade de aprender.

Este é o guia definitivo do zero absoluto ao seu primeiro app funcionando.

## Por Que IA Mudou Tudo na Programação

Antes, aprender a programar era tipo aprender um novo idioma do zero. Você precisava memorizar gramática (sintaxe), vocabulário (funções e métodos), e praticar por meses até conseguir formar uma "frase" que funcionasse.

Agora? A IA funciona como um copiloto que já sabe todos os idiomas. Você só precisa comunicar o que quer, e ela escreve o código com você.

Não é mágica. Você ainda precisa aprender lógica, entender conceitos, debugar problemas. Mas a barreira de entrada despencou. Um projeto que antes levaria meses para um iniciante pode ser feito em dias com a ajuda certa.

## O Que Você Vai Precisar

Vamos desmistificar logo: você **não precisa** de:

- Mac caro
- Curso de R$ 5.000
- Saber matemática avançada

Você **precisa** apenas de:

- Um computador (Mac, Windows, ou Linux)
- Conexão com internet
- Vontade de aprender
- Tempo (vamos gastar uns 30 minutos hoje)

É isso. Literalmente.

## Passo 1: Setup Inicial - Baixando o Cursor

Vamos usar o **Cursor**, uma ferramenta que desenvolvedores profissionais usam, mas com IA integrada que torna tudo mais acessível.

**Como fazer:**

1. Vá em **cursor.com**
2. Clique no botão de download (ele detecta automaticamente seu sistema)
3. Aguarde o download terminar
4. No Mac: arraste para a pasta Applications
5. No Windows: execute o instalador e siga o assistente
6. Abra o Cursor

Pronto! Você acabou de instalar a mesma ferramenta que devs com 10 anos de experiência estão usando hoje.

## Passo 2: Criando Seu Primeiro Projeto

Agora vem um conceito importante: **todo código vive dentro de pastas** (devs chamam de "diretórios").

Pense assim: se o código fosse um livro, a pasta é a estante onde você guarda esse livro. Cada projeto tem sua própria pasta.

**Vamos criar a sua:**

1. Abra o seu Desktop (área de trabalho)
2. Clique com botão direito → Criar Nova Pasta
3. Dê o nome de **"meu-primeiro-app"**
4. Agora no Cursor: **File → Open Folder**
5. Selecione a pasta "meu-primeiro-app" que você acabou de criar

Conceito-chave que você precisa gravar: **Pasta = Projeto**. Sempre que for criar algo novo, crie uma pasta nova.

## Passo 3: Entendendo o Ambiente do Cursor

Olhe para a tela do Cursor. Ela está dividida em três partes principais:

- **Esquerda**: Seus arquivos e pastas (vazio por enquanto, normal)
- **Centro**: Onde você vai editar o código
- **Chat**: A interface de IA estilo ChatGPT (pode estar na lateral ou embaixo)

A grande sacada do Cursor é que, diferente de sites como ChatGPT, **o código fica no seu computador**. Você controla tudo. Você é dono dos arquivos.

A IA apenas te ajuda a escrever esse código mais rápido e melhor.

## Passo 4: Criando Seu Primeiro Código

Chegou a hora. Vamos criar uma página web simples que funciona de verdade.

**No chat do Cursor**, digite exatamente isso:

> *"Crie um arquivo index.html simples com um título 'Olá, Mundo!' e um parágrafo dizendo que é meu primeiro código criado com IA"*

Aperte Enter e veja a mágica acontecer.

<!-- TODO: Adicionar screenshot do chat criando HTML -->

A IA vai sugerir criar um arquivo e escrever o código. Aceite a sugestão. Você verá algo assim aparecer no seu editor:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Meu Primeiro App</title>
</head>
<body>
    <h1>Olá, Mundo!</h1>
    <p>Meu primeiro código criado com IA!</p>
</body>
</html>
```

Não precisa entender tudo agora. Mas veja que:

- `<h1>` é um título grande
- `<p>` é um parágrafo
- Tudo entre `<body>` aparece na página

## Passo 5: Vendo Seu App Funcionando

Agora a parte mais legal: **abrir sua criação no navegador**.

1. No Cursor, clique com botão direito no arquivo **index.html** (na barra esquerda)
2. Escolha "Reveal in Finder" (Mac) ou "Reveal in File Explorer" (Windows)
3. Dê um duplo clique no arquivo index.html

BOOM. Seu navegador vai abrir e mostrar sua página funcionando.

## Erros Comuns (e Como Resolver)

Todo desenvolvedor erra. É parte do processo. Aqui estão os erros mais comuns de quem está começando:

### 1. "Não consigo abrir a pasta no Cursor"

**Solução**: Certifique-se de que você criou a pasta primeiro no Desktop. O Cursor precisa de uma pasta existente para abrir.

### 2. "O código não funciona no navegador"

**Solução**: Verifique se salvou o arquivo (Ctrl+S ou Cmd+S). O arquivo precisa estar salvo antes de abrir no navegador.

### 3. "A IA sugeriu um código muito complexo"

**Solução**: Seja específico no seu pedido. Adicione "simples" ou "para iniciantes" na sua instrução.

### 4. "Não entendo o que o código faz"

**Solução**: Pergunte ao Cursor! Digite "Explica esse código linha por linha" e a IA vai te explicar.

### 5. "Tenho medo de quebrar algo"

**Solução**: Relaxe. O pior que pode acontecer é você deletar a pasta e criar outra. Não dá para quebrar o computador escrevendo código HTML.

Lembre-se: **errar faz parte**. Devs com 20 anos de experiência (como eu) ainda passam metade do dia debugando erros. A diferença é que agora temos IA para ajudar.
