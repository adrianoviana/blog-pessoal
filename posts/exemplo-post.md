# Exemplo de Post - Como Usar Markdown

Este é um post de exemplo mostrando como criar conteúdo em Markdown para o blog.

## O que é Markdown?

Markdown é uma linguagem de marcação leve que você pode usar para adicionar formatação a documentos de texto simples.

## Como Criar um Post

Para criar um novo post, siga estes passos:

1. Crie um arquivo `.md` no diretório `/posts`
2. Adicione o frontmatter (metadados) no início
3. Escreva seu conteúdo usando Markdown
4. Execute o script de build para gerar o HTML

## Exemplo de Código

```javascript
function saudacao(nome) {
  console.log(`Olá, ${nome}!`);
}

saudacao("Mundo");
```

## Formatação de Texto

Você pode usar **negrito**, *itálico*, e `código inline`.

### Lista de Recursos

- Markdown simples
- Frontmatter YAML
- Syntax highlighting
- Imagens responsivas
- Tags e categorias

## Conclusão

Markdown torna a escrita de posts muito mais simples e focada no conteúdo!
